# Trinktribunal

**Trinktribunal** ist ein Party- und Trinkspiel, bei dem ihr eure Mitspieler anhand ihrer Antworten in die richtige Reihenfolge bringen müsst.

## Spielidee

1. Eine Karte eröffnet einen neuen „Fall“ mit einer Frage oder einer ungewöhnlichen Situation.
2. Jeder Spieler erhält eine geheime Zahl und gibt eine Antwort, die zu dieser Zahl passt.
3. Der „Richter“ versucht, alle Spieler anhand ihrer Antworten richtig zu sortieren.
4. Die Zahlen werden aufgedeckt – und das Urteil steht fest.

## Spielwelt

Das Spiel ist als humorvoller Cartoon-Gerichtssaal gestaltet. Die Spieler treten als kleine Getränkefiguren mit Namen auf, die sich optisch individualisieren lassen. Die Sortierreihenfolge wird auf der Anklagebank sichtbar.
